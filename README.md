# Huida del lunes

Juego de mesa original para un jugador: es lunes y quieres escapar de la oficina. Recoge en las impresoras el informe de cada compañero, llévaselo para que te cubra (y te dé café, una excusa o una llamada falsa) y sal por la puerta antes de las 18:00 sin que te pille el jefe, que patrulla, mira en línea recta y se mueve con cartas que ves de antemano. Oficina del día y oficinas al azar en tres dificultades.

🔗 **Jugar ahora:** https://adrianezd.github.io/huida-del-lunes/

Sitio estático sin dependencias ni build (HTML, CSS y JavaScript vanilla) servido por GitHub Pages. Funciona sin conexión gracias a `sw.js`. Los récords se guardan solo en tu navegador (`localStorage`).
